{# The interactive day-two page (INIT-005). Deliberately not a form. The old page asked for a switch, a VLAN number and a VLAN name as three inputs, which made the operator the integration layer: they had to know which VLAN a service used and which switches it belonged on, and nothing tied the value to IPAM — you could configure a switch with a VLAN NetBox had never heard of. Here, choosing an *operation* re-renders the inputs, and every input that names something in NetBox is populated from NetBox. The VLAN list comes from ipam.vlan. There is nowhere to type a VLAN number, because there is no reason to: the network's own record is the menu. JavaScript is inline on purpose. This plugin has no static asset pipeline (the ZTP portal's static needed pre-copying in the Dockerfile after collectstatic failed to pick it up), and a demo page that cannot load its JS is a blank panel in front of a customer. #}
